### 2. Installation

First, install the necessary dependencies.

`npm install`

`npx playwright install`

### 3. Running Tests

To execute the entire test suite, run the following commands:

`npx playwright test`
`npx playwright test --headed`
`npx playwright test --headed --project=firefox`


### 4. Viewing Reports

After a test run is complete, a report is generated.

`npx playwright show-report`
